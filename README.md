## システム構成（7モジュール）

| モジュール | 用途 | 主な実装機能 |
|:--|:--|:--|
| **`public`** | 公開情報 | 経済イベントカレンダー、市場情報表示、データ連携 |
| **`portfolio`** | 取引・資産管理 | 取引データ管理、日付別損益集計、CSV/JSONバックアップ |
| **`fx`** | FX分析 | 手動／自動売買分類、通貨ペア・口座・戦略別、日／週／月／年集計 |
| **`market`** | 市場情報 | 相場履歴、ウォッチリスト、経済イベント、投資信託、FXCenter |
| **`workbench`** | 共通管理 | ログイン、ダッシュボード、ユーザー・権限管理、診断 |
| **`download`** | 配布・保全 | ファイル分類・ダウンロード、DB／サイトバックアップ、容量確認 |
| **`deploy`** | リリース支援 | 差分確認、事前チェック、変更プレビュー、公開・履歴管理 |

## 技術的な取り組み

### データ管理・分析
- `portfolio` / `fx`：取引区分、口座、通貨ペア、期間など、複数条件での集計と表示を整理。
- `market` / `public`：市場データの更新・履歴管理と、公開画面での情報表示を分離。

### 運用管理・自動化
- `workbench`：管理者と一般利用者の権限を分け、複数機能を共通画面から管理。
- `download`：MySQL・Webサイトのバックアップとディスク容量の確認を支援。
- `deploy`：**差分確認 → 事前チェック → プレビュー → 公開 → 履歴確認**の流れを整備し、更新ミスの低減を図る。

## 生成AIの活用と品質確認

生成AIは**開発支援ツール**として利用しています（システムへのAI API組込みを意味するものではありません）。

- **要件・設計：** 仕様整理、実装方法の比較、画面・DB設計の検討
- **実装・改修：** PHP / JavaScript / SQLのコード案作成、既存機能の修正
- **テスト・保守：** 不具合原因の調査、テスト観点整理、動作確認

AIの出力はそのまま採用せず、既存仕様との整合性や動作を自ら確認し、必要に応じて修正しています。
